# Smart Digital Expense Tracker with Budget Prediction

**Course:** BCA 1st Semester (2026–2027)

## Project Description
A C++ based expense management system that helps users record daily expenses, manage monthly budgets, track spending and predict future expenses.

## Features
- User Registration
- Login System
- Add Daily Expense
- View Expense History
- Category-wise Expense
- Monthly Expense Report
- Budget Setting
- Budget Warning
- Expense Prediction
- Search Expense
- Delete Expense
- File Saving

## Technologies Used
- Programming Language: C++
- IDE: Code::Blocks / VS Code
- Concepts: Variables, Loops, Arrays, Structures, Functions and File Handling.

## How to Run
1. Download `main.cpp`.
2. Open it in a C++ IDE.
3. Compile and run the program.
